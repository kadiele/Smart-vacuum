Architettura del Sistema 

Immagine griglia → Preprocessing → Segmentazione celle
        ↓
CNN (EMNIST) → Riconoscimento lettere
        ↓
Matrice di stati
        ↓
Algoritmi di ricerca (A*, BFS)
        ↓
Simulazione percorso

Obiettivi del progetto
Riconoscere automaticamente una griglia da immagine
Trasformare l’immagine in un problema di ricerca
Identificare lettere/oggetti tramite CNN (EMNIST)
Risolvere il problema con algoritmi di ricerca (A*, BFS)
Visualizzare passo dopo passo il movimento del robot
